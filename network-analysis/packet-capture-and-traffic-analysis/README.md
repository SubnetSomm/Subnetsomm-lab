# Packet capture and traffic analysis

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Generate traffic and interpret it through packet-level observations.

## Learning objectives

- Select relevant packets from a capture.
- Relate protocol fields to generated activity.
- Distinguish observations from labels such as malicious.

## Workflow

1. Configure Wireshark and generate the prescribed lab traffic.
2. Inspect and filter the resulting packets.
3. Repeat the analysis in the applied-learning scenario.
4. Generate and analyze the simulated malicious traffic challenge.

## Results and learning

The saved report records ordinary and simulated malicious traffic tasks. This entry complements the separate host/port-identification exercise: packet analysis is strongest when the traffic source and expected behavior are documented alongside the filter and result.
