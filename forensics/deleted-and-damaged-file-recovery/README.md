# Deleted and damaged file recovery

**Author:** Franco Pisano · **Context:** ITN 276 · Spring 2026 · **Type:** Guided lab

## Purpose

Recover artifacts from supplied images and damaged files across several filesystem contexts.

## Learning objectives

- Distinguish filesystem-aware recovery from ordinary file access.
- Compare recovery workflows across filesystems.
- Record the recovered artifact and the tool used.

## Workflow

1. Recover deleted NTFS artifacts with E3.
2. Work through the damaged-file/archive recovery tasks.
3. Recover the challenge file from a FAT32 image.
4. Use Autopsy for the APFS image challenge.

## Results and learning

The saved submission contains recovery captures for NTFS, FAT32 and APFS tasks, including a RAR-related recovery stage. Recovery depends on the available evidence and filesystem state; these lab results should not be generalized into a guarantee that deleted files are always recoverable.

- Recover Deleted Files from an Ext4 Drive Image with Autopsy

- Recover Deleted Files from a APFS Drive Image
