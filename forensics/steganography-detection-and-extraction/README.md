# Steganography detection and extraction

**Author:** Franco Pisano · **Context:** ITN 276 · Spring 2026 · **Type:** Guided lab

## Purpose

Detect concealed information in supplied forensic evidence and recover hidden content.

## Learning objectives

- Recognize artifacts associated with data concealment.
- Distinguish a carrier from its extracted payload.
- Document detection and extraction as separate analytical steps.

## Workflow

1. Search a supplied drive image for evidence of steganography software.
2. Inspect candidate carrier files and perform extraction tasks.
3. Identify additional carriers and recover their concealed content.

## Results and learning

The written challenge response identifies two supplied BMP files as containing hidden data, with extraction results recorded in the saved report. This illustrates why a normal-looking image is not sufficient evidence that a file contains only visual content.
