# Secure topology planning lab

**Author:** Franco Pisano · **Context:** ITN 263 · Summer 2026 · **Type:** Guided lab

## Purpose

Plan a network layout with explicit security boundaries.

## Learning objectives

- Connect network placement with trust boundaries.
- Explain the purpose of separating public and internal resources.
- Document a topology clearly enough to discuss allowed traffic.

## Workflow

1. Inspect the supplied network and its required services.
2. Work through the topology-design tasks and document the resulting layout.
3. Complete the applied-learning and challenge stages in the saved submission.

## Results and learning

The completed report records the topology exercise. This guided lab is separate from the Corporation Techs architecture capstone, which contains the longer business requirements, platform choices and rollout proposal.

## Coverage of the saved report

The submission includes these stages (original stage labels):

- Design a Simple Network Topology
- Capture Network Traffic to Validate Connectivity
- Design a More Complex Network Topology
- Enhance the Network Topology with a DMZ
- Validate DMZ Connectivity
