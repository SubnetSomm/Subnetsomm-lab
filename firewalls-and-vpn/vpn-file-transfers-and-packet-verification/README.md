# VPN file transfers and packet verification

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Compare secure and insecure file-transfer observations through a Windows VPN workflow.

## Learning objectives

- Relate a configured tunnel to packet evidence.
- Explain how encryption changes payload visibility.
- Distinguish connection success from policy verification.

## Workflow

1. Configure the Windows VPN client.
2. Compare protected and unprotected transfer captures.
3. Implement the custom IPsec-policy challenge.
4. Inspect the VPN exchange in Wireshark.

## Results and learning

The report records client setup, transfer comparison, custom policy and capture verification. This is distinct from the ITN 263 server/client sequence: its organizing question is what the observer can see during a transfer.
