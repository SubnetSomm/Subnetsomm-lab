# pfSense penetration testing and remediation analysis

**Author:** Franco Pisano · **Context:** ITN 263 · Summer 2026 · **Type:** Guided lab

## Purpose

Assess a supplied firewall environment and translate findings into corrective actions.

## Learning objectives

- Connect exposure with an actionable finding.
- Prioritize management access and unnecessary services.
- Separate remediation recommendations from verified fixes.

## Workflow

1. Inspect the WAN configuration.
2. Conduct the scoped lab penetration-test workflow.
3. Review exposed management and web-server services.
4. Document corrective actions and a verification plan.

## Results and learning

My written recommendations include changing default credentials, restricting WebGUI/SSH to trusted management access, tightening DMZ-to-LAN rules, replacing cleartext FTP where needed, patching and rescanning. These are proposed corrections; the entry does not claim the saved recommendation text proves that all fixes were applied and retested.
