# Windows Defender Firewall configuration

**Author:** Franco Pisano · **Context:** ITN 263 · Summer 2026 · **Type:** Guided lab

## Purpose

Practice host-level traffic control in the supplied Windows environment.

## Learning objectives

- Relate a rule’s scope to the traffic it controls.
- Use verification traffic to assess a configuration change.
- Recognize host firewalling as a separate defensive layer.

## Workflow

1. Inspect the Windows firewall configuration.
2. Apply the exercise’s rule changes.
3. Record the prescribed connectivity and verification outputs.

## Results and learning

The saved report records the configuration and verification tasks. The separate Windows custom-rule entry adds a concrete before/after example involving ICMP and outbound HTTP.
