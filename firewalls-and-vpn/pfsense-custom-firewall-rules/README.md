# pfSense custom firewall rules

**Author:** Franco Pisano · **Context:** ITN 263 · Summer 2026 · **Type:** Guided lab

## Purpose

Translate intended traffic flows into interface-specific policy and tests.

## Learning objectives

- Translate business traffic needs into explicit rules.
- Relate rule placement to packet direction.
- Test allowed access and inspect denied traffic.

## Workflow

1. Plan the LAN rules in the lab worksheet.
2. Apply the custom rule configuration.
3. Test permitted paths in the supplied scenario.
4. Complete the VPN-access and ICMP-rule challenges.

## Results and learning

The report records rule planning, applied configuration and connectivity challenges, including VPN access and an ICMP log/rule task. A successful connection is meaningful only in relation to the rule and interface intended to allow it.
