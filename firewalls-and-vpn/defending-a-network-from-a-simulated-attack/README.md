# Defending a network from a simulated attack

**Author:** Franco Pisano · **Context:** ITN 263 · Summer 2026 · **Type:** Guided lab

## Purpose

Observe a simulated attack and apply layered network/host defenses.

## Learning objectives

- Explain why host and perimeter controls complement each other.
- Document changes alongside the activity they address.
- Distinguish a benign antivirus test artifact from live malware.

## Workflow

1. Work through the supplied attack-and-defense scenario.
2. Inspect the affected host and network controls.
3. Run the antivirus challenge using the EICAR test artifact.
4. Harden the perimeter rules in the DMZ exercise.

## Results and learning

The report records the guided defense workflow, EICAR detection and DMZ-rule changes. Completion of a test confirms behavior for that scenario; it does not establish protection against all attack variants.
