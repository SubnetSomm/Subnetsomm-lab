# Web application and database attack analysis

**Author:** Franco Pisano · **Context:** ITN 261 · Summer 2026 · **Type:** Guided lab

## Purpose

Explore input-handling weaknesses in deliberately vulnerable web applications.

## Learning objectives

- Distinguish client-side script execution from database-query manipulation.
- Use application responses as evidence.
- Connect unsafe input handling with mitigation needs.

## Workflow

1. Complete the DVWA cross-site scripting tasks.
2. Work through database-attack tasks in the supplied Juice Shop environment.
3. Use error behavior and query results to understand the database exercise.
4. Document the reflected-XSS challenge.

## Results and learning

The report documents XSS output, database error/structure observations and a reflected-XSS challenge. These exercises illustrate different trust boundaries; successful input handling requires context-appropriate controls rather than one universal filtering rule.
