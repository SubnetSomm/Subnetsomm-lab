# Active reconnaissance and service enumeration

**Author:** Franco Pisano · **Context:** ITN 261 · Summer 2026 · **Type:** Guided lab

## Purpose

Map reachable lab services and turn scan observations into investigation leads.

## Learning objectives

- Interpret host and service discovery.
- Relate scan behavior to observed packets.
- Use vulnerability findings as leads requiring validation.

## Workflow

1. Discover hosts and services with Zenmap.
2. Inspect vulnerability information for the supplied targets.
3. Capture traffic produced by a UDP scan.
4. Create and test a custom Zenmap profile.

## Results and learning

The submission documents scanning, vulnerability review, a UDP-capture challenge and a custom scan profile. These are complementary views: a scan summarizes responses while a packet capture helps explain how those responses were obtained.
