# John the Ripper password audit

**Author:** Franco Pisano · **Context:** ITN 266 · Summer 2026 · **Type:** Documented coursework exercise

## Purpose

Compare dictionary and brute-force approaches using supplied test hashes.

## Learning objectives

- Explain guess-and-compare hash auditing.
- Relate search space to cost and coverage.
- Distinguish test credentials from real user data.

## Workflow

1. Prepare the exercise folder and install John the Ripper.
2. Place the supplied password file.
3. Run the dictionary and brute-force exercise stages.
4. Inspect the John.pot result file.

## Results and learning

My written answers explain that auditing compares guessed hashes rather than decrypting a stored hash. A larger wordlist increases possible coverage but does not automatically make a complete search faster. Supplied hashes and recovered credentials are not published.
