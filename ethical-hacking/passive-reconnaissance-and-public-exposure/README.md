# Passive reconnaissance and public exposure

**Author:** Franco Pisano · **Context:** ITN 261 · Summer 2026 · **Type:** Guided lab

## Purpose

Understand how publicly available information can reveal an organization’s exposed assets and social-engineering context.

## Learning objectives

- Distinguish passive information gathering from active probing.
- Connect public exposure to assessment scope.
- Explain the security relevance of otherwise ordinary public details.

## Workflow

1. Use scoped public-search techniques in the lab scenario.
2. Collect and organize public-facing information relevant to assessment planning.
3. Explain how public information could guide later authorized testing.
