# Packet and disk evidence incident investigation

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Correlate network and disk evidence in a supplied incident scenario.

## Learning objectives

- Use more than one evidence source.
- Distinguish a suspicious artifact from an explained finding.
- Connect observations to an incident narrative.

## Workflow

1. Analyze a PCAP for relevant activity.
2. Inspect the supplied disk image for corroborating evidence.
3. Investigate additional email and spyware artifacts.
4. Assess further indications of data exfiltration.

## Results and learning

The completed report documents packet, disk, email and spyware/exfiltration tasks. A useful incident narrative must connect those sources rather than treating each screenshot as a separate answer. This entry preserves the investigation sequence without publishing the supplied raw evidence.
