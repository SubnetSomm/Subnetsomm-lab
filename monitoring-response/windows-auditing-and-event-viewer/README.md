# Windows auditing and Event Viewer

**Author:** Franco Pisano · **Context:** ITN 266 · Summer 2026 · **Type:** Documented coursework exercise

## Purpose

Enable authentication auditing and interpret the corresponding event records.

## Learning objectives

- Connect audit policy with generated records.
- Distinguish authentication context and event fields.
- Document environment substitutions.

## Workflow

1. Enable success/failure account-logon and logon auditing.
2. Inspect Security logs before and after a logon/logoff cycle.
3. Open event details rather than relying only on the list view.
4. Use the PowerShell application log because Office was not installed.

## Results and learning

The submission records the Office-to-PowerShell log substitution explicitly. My reflection distinguishes endpoint logon records from authentication events that may occur on a domain controller. The substituted log demonstrates application-specific logging without claiming the unavailable Office log was examined.
