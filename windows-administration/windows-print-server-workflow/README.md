# Windows print server workflow

**Author:** Franco Pisano · **Context:** ITN 200 · Spring 2026 · **Type:** Documented coursework exercise

## Purpose

Configure and inspect print services in the supplied server environment.

## Learning objectives

- Describe centralized printer administration.
- Distinguish server, printer and job settings.
- Verify that a shared resource is available over the network.

## Workflow

1. Document the Print Server installation stage.
2. Inspect Print Management and server/printer properties.
3. Review a print job and its priority settings.
4. Connect a shared printer from another machine and inspect network access.
