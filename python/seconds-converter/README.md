# Seconds converter

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Convert an entered number of seconds into hours, minutes and seconds.

## Learning objectives

- Combine quotient and remainder operations.
- Name conversion constants.
- Explain input assumptions.

## Workflow

1. Read the total seconds.
2. Use integer division for whole hours and minutes.
3. Use modulo for remainders and display the components.

## Results and learning

The calculation is a compact demonstration of floor division and modulo. The coursework version expects integer input; handling invalid or negative entries is a possible extension.

## Run the original program

Requires Python 3 and the standard library.

```bash
python3 seconds_converter.py
```

The source preserves the coursework version. See the limitations above before extending it.
