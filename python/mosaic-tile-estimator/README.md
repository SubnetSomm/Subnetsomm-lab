# Mosaic tile estimator

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Estimate tile material for a circular tabletop with a waste allowance.

## Learning objectives

- Translate a geometry problem into arithmetic.
- Use constants to make assumptions explicit.
- Explain the limits of an area-based estimate.

## Workflow

1. Read tabletop diameter and tile dimensions.
2. Calculate tabletop and tile areas.
3. Apply the 20 percent waste factor and display the estimate.

## Results and learning

The source preserves the original arithmetic and output. The estimate does not model the exact tile layout or cutting pattern. Zero/negative dimensions and the rounding needed when purchasing whole tiles deserve explicit handling in a future revision.
