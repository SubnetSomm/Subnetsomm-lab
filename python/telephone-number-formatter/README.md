# Telephone number formatter

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Switch between compact and parenthesized phone-number representations.

## Learning objectives

- Use string slicing and concatenation.
- Separate format recognition from transformation.
- Consider malformed and unexpected inputs.

## Workflow

1. Read a supplied number string.
2. Inspect its length and formatting markers.
3. Use slices and concatenation to produce the alternate representation.

## Results and learning

The original utility targets the fixed formats described in its header. It is a classroom formatting exercise rather than a complete international telephone-number validator.

## Run the original program

Requires Python 3 and the standard library.

```bash
python3 telephone_number.py
```

The source preserves the coursework version. See the limitations above before extending it.
