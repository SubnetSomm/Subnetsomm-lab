# Arithmetic functions

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Demonstrate arithmetic functions with a formatted result display.

## Learning objectives

- Separate calculation from presentation.
- Pass parameters and return results.
- Reuse a display function.

## Workflow

1. Pass the sample numbers to individual arithmetic functions.
2. Return the calculated values.
3. Display the operator and formatted result.

## Results and learning

The original is a small function demonstration with fixed sample values. It is included as a foundations entry rather than a full interactive calculator.

## Run the original program

Requires Python 3 and the standard library.

```bash
python3 function_calculator.py
```
