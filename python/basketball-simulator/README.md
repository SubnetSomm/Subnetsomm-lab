# Basketball simulator

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Simulate a two-player basketball game with random point values and reusable functions.

## Learning objectives

- Decompose a program into input, scoring and display functions.
- Use nested iteration and pseudorandom values.
- Maintain state across repeated events.

## Workflow

1. Read two player names.
2. Run four quarters with repeated randomized shot outcomes.
3. Update both scores and display the winner or tie.

## Results and learning

The program implements four quarters and 24 shot intervals per quarter for each player. Random values from 0 to 3 map to missed shots and point outcomes. It is an educational simulation, with no claim to a realistic probability model.

## Run the original program

Requires Python 3 and the standard library.

```bash
python3 basketball_game_with_functions.py
```

The source preserves the coursework version. See the limitations above before extending it.
