# Temperature analysis

**Author:** Franco Pisano · **Context:** ITP 150 · Spring 2026 · **Type:** Coursework program

## Purpose

Collect daily temperatures and calculate descriptive summaries.

## Learning objectives

- Collect repeated input using loops.
- Store related values and calculate summaries.
- Validate a meaningful lower bound for record count.

## Workflow

1. Choose a positive number of days.
2. Enter dates and low/high values into parallel lists.
3. Calculate daily averages and summary statistics.

## Results and learning

The original includes a check that the number of days is at least one. Numeric parsing and inconsistent low/high values need additional validation. A companion two-dimensional version preserves another approach to representing the same records.

## Run the original program

Requires Python 3 and the standard library.

```bash
python3 temperatures.py
```

The source preserves the coursework version. See the limitations above before extending it.
