# Public key and symmetric file encryption

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Compare shared-secret and public-key workflows for protecting files.

## Learning objectives

- Distinguish shared-secret protection from key-pair use.
- Explain the role of recipient keys.
- Validate that decrypted content is usable.

## Workflow

1. Create the lab encryption keys.
2. Encrypt and decrypt a supplied file.
3. Compare symmetric and asymmetric encryption tasks.
4. Securely exchange and decrypt the authentication-log exercise.

## Results and learning

The report records key creation, encryption/decryption and a secure-exchange challenge. The learning distinction is operational: symmetric encryption requires a shared secret, while public-key exchange still requires confidence that the recipient key belongs to the intended person.
