# VeraCrypt encrypted container

**Author:** Franco Pisano · **Context:** ITN 266 · Summer 2026 · **Type:** Documented coursework exercise

## Purpose

Create and use an encrypted file container.

## Learning objectives

- Distinguish an encrypted container from an ordinary text file.
- Explain mounted access and key dependence.
- Separate performed tasks from conceptual discussion.

## Workflow

1. Select a container path and AES in the creation workflow.
2. Mount the encrypted volume.
3. Place a text file inside and document the resulting container.
4. Discuss keyfiles and hidden volumes as additional concepts.

## Results and learning

The submission documents container creation and use. Hidden volumes and whole-device encryption appear in the reflection; this entry does not claim they were implemented in the saved exercise.
