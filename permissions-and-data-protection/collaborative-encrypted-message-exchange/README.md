# Collaborative encrypted message exchange

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Documented coursework exercise

## Purpose

Compare symmetric/asymmetric encryption and exchange a protected message with a classmate.

## Learning objectives

- Compare shared-secret and recipient-key workflows.
- Distinguish public-key exchange from sharing private keys.
- Document decryption as an end-to-end check.

## Workflow

1. Create encrypted ccrypt and GPG artifacts.
2. Decrypt content and export a public key.
3. Import the collaborator’s key and encrypt a new message to that recipient.
4. Receive and decrypt the collaborator’s protected message.

## Results and learning

My submission records collaboration to resolve unclear instructions and includes encryption, import/export and decryption captures. Peer messages, identities and key files are excluded from the public version.
