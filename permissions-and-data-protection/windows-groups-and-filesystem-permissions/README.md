# Windows groups and filesystem permissions

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Implement role-based folder access with graphical tools and PowerShell.

## Learning objectives

- Map access requirements to groups.
- Distinguish group membership from resource permissions.
- Inspect effective configuration before changing it.

## Workflow

1. Create security groups and the required folder structure.
2. Assign folder permissions to the intended groups.
3. Repeat group/permission tasks in PowerShell.
4. Modify group structure, audit permissions and apply changes.

## Results and learning

My challenge analysis proposes grouping student and faculty access by role instead of maintaining separate per-user permissions. The saved report documents group creation and permission inspection/modification. A good access-control write-up pairs intended access with positive and negative access tests.
