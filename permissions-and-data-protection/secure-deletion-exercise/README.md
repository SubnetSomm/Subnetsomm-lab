# Secure deletion exercise

**Author:** Franco Pisano · **Context:** ITN 266 · Summer 2026 · **Type:** Documented coursework exercise

## Purpose

Observe file deletion and free-space wiping in the Eraser exercise.

## Learning objectives

- Distinguish ordinary deletion from an overwrite task.
- Record limitations in evidence capture.
- Avoid equating a completion message with a recovery experiment.

## Workflow

1. Run the unused-space task on the 100 MB lab volume.
2. Record the completed status because the small task finished before an in-progress capture.
3. Delete the designated test file through Eraser.
4. Document the difficulty with the right-click interface.

## Results and learning

The saved account records completed Eraser tasks and a UI workaround. No independent recovery test is established here. Storage behavior, including SSD remapping and snapshots, limits any blanket claim that an overwrite utility proves all copies unrecoverable.
