# EFS and BitLocker data protection

**Author:** Franco Pisano · **Context:** ITN 262 · Summer 2026 · **Type:** Guided lab

## Purpose

Compare file-level encryption with volume-level protection in Windows.

## Learning objectives

- Describe the scope of file versus volume protection.
- Recognize the importance of key/recovery access.
- Separate encrypted storage from authorization decisions.

## Workflow

1. Configure EFS and test the exercise’s access behavior.
2. Install/configure and work with BitLocker in the lab.
3. Complete the encrypted-file sharing task.
4. Work through encryption/decryption automation challenges.

## Results and learning

The report documents EFS security tests, BitLocker configuration and automation challenges. These mechanisms protect different scopes. An encrypted volume that is already unlocked and a file accessible to an authorized account still require ordinary access control and endpoint protection.
