# Interactive Bash greeting

**Author:** Franco Pisano · **Context:** ITN 170 · Fall 2025 · **Type:** Documented coursework exercise

## Purpose

Create and run a simple shell script using user input.

## Learning objectives

- Use shell input and output.
- Distinguish explicit-interpreter execution from direct execution.
- Relate script permissions to invocation.

## Workflow

1. Create welcome.sh with a shell interpreter line and explanatory comment.
2. Read first and last names and print a greeting.
3. Run with bash, then add execute permission.
4. Verify the mode and run it directly with ./welcome.sh.

## Results and learning

The written account records both execution methods and chmod verification. The original standalone script was not located, so this entry describes the documented work instead of presenting a later reconstruction as the original file.
