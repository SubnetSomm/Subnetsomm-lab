# Personal Budget Tracker

**Author:** Franco Pisano · **Context:** ITP 100 · Fall 2025 · **Type:** Programming design project

## Purpose

Design a console budget tracker from a user problem through flowchart and modular pseudocode.

## Learning objectives

- Translate a user problem into requirements.
- Use decisions and loops to describe control flow.
- Separate input, processing, file logging and output responsibilities.

## Workflow

1. Analyze a freelance designer’s income/expense tracking needs.
2. Define transaction inputs, categories, summaries and realistic initial scope.
3. Map transaction decisions and repeated entry in a flowchart.
4. Write modular pseudocode for validation, category totals, balance summaries and CSV logging.

## Results and learning

This is a design/pseudocode project. No executable implementation is claimed. The original design discusses GUI, secure login and cloud access as possible later work. The final pseudocode appends a transaction log and initializes totals at startup; restoring prior history and satisfying every initial requirement need a separate implementation review.
